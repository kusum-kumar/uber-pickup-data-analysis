# Uber Pickup Data Analysis — New York City (2014)

## Project Overview
This project explores Uber pickup patterns across New York City using six months of trip data from April to September 2014. The analysis focuses on hourly pickup activity and geographic visualization.

## Project Objectives
- Combine six monthly Uber datasets.
- Clean and prepare data using Python and Pandas.
- Analyze pickup activity by hour.
- Visualize geographic pickup density using an interactive heatmap.

## Tools & Technologies
- **Python** — Data analysis
- **Pandas** — Data cleaning and preparation
- **Jupyter Notebook** — Development environment
- **Folium** — Interactive map visualization

## Project Workflow
1. Imported and combined six monthly CSV datasets.
2. Cleaned date/time and geographic fields.
3. Extracted hourly features from pickup timestamps.
4. Grouped pickup coordinates by hour.
5. Created an interactive heatmap to explore pickup density over time.

## Dataset
- **Period:** April–September 2014
- **Records:** Approximately 4.53 million
- **Location:** New York City

## Repository Contents
- `uber_pickup_analysis.ipynb` — Jupyter Notebook containing the analysis.

## How to Run
1. Clone or download this repository.
2. Install the required Python libraries, including Pandas and Folium.
3. Obtain the original Uber CSV datasets and place them in the expected directory.
4. Open the notebook in Jupyter Notebook or JupyterLab.
5. Run the notebook cells in order.
